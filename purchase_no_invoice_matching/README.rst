Purchase - No Invoice Matching
##############################

Allows to disable auto matching between purchase and vendor bills. It is
useful, when you want to only manually relate it as odoo can automatically
match it in some unexpected ways.

Configuration
=============

Go to ``Purchase / Configuration / Settings / Orders`` and select ``No Vendor Bills Matching``.
